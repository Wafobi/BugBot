TTS – Stimmen & Pool

Läuft auf dem Server, mit den dort installierten Stimmen. Speichern landet in settings/tts.json auf dem Server (überlagert die tts.json aus dem Repo) – gilt sofort.

Sprechweise

Gilt für alle Stimmen. „Std.“ = Wert des jeweiligen Modells; ↺ setzt einen Regler darauf zurück.

Stimmen-Pool

Im Stream spricht eine Stimme aus diesem Pool. Klick auf eine Stimme lädt sie oben, × entfernt sie.
