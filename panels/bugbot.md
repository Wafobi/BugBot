**Was ist BugBot?**

[BugBot](https://github.com/Wafobi/BugBot) ist mein selbst entwickelter Stream-Bot: Er
moderiert den Chat, beantwortet Befehle und hält Statistiken zum Stream fest – hier bei
Twitch ebenso wie auf meinem Discord-Server.

Die Companions im Chat sind eines seiner Module, gebaut auf demselben System wie der Rest
des Bots.

BugBot ist quelloffen und frei verfügbar; der vollständige Code steht auf GitHub, falls du
dir einen eigenen Bot bauen möchtest.

🤖 [Auf GitHub ansehen](https://github.com/Wafobi/BugBot)
