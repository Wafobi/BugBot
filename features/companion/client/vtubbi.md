**Was ist vtubbi?**

[vtubbi](https://github.com/Wafobi/vtubbi) ist mein selbst entwickeltes
VTuber-Avatar-Projekt, das mich anstelle einer klassischen Webcam als animierten Avatar im
Stream zeigt.

Die Companions hier im Chat sind ein Ableger desselben Projekts – dieselbe Grundlage, nur als
kleiner Begleiter für dich statt als Avatar für mich.

vtubbi ist quelloffen und frei verfügbar; der vollständige Code steht auf GitHub, falls du
dir ein eigenes Setup bauen möchtest.

⭐ [Auf GitHub ansehen](https://github.com/Wafobi/vtubbi)
