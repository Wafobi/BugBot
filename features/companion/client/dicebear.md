**Was ist DiceBear?**

[DiceBear](https://www.dicebear.com/) ist ein kostenloser Avatar-Generator, aus dessen
"Sprouts"-Stil die Looks der Companions hier im Chat stammen.

🎲 [dicebear.com](https://www.dicebear.com/)

Hinweis: DiceBear ist eine Marke der jeweiligen Rechteinhaber. vtubbi und WafobiTV stehen in
keiner geschäftlichen Verbindung zu DiceBear und werden von DiceBear weder unterstützt noch
gesponsert; genutzt wird ausschließlich die öffentlich zugängliche API zur Erzeugung der
Avatare.
